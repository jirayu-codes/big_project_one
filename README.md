# PlantPal

PlantPal helps people stop forgetting when to water, fertilize, or repot their
plants. You can add a plant and see when it is next due to be watered.

## Project Constitution

The constitution is the durable, high-level foundation of this project:

- [SPECS/MISSION.md](SPECS/MISSION.md) — why the project exists, its values, and its non-negotiables.
- [SPECS/TECH.md](SPECS/TECH.md) — the technology stack and engineering standards.
- [SPECS/ROADMAP.md](SPECS/ROADMAP.md) — the current state and where the project is going.

Feature details live in dated feature-spec folders, not in the constitution.

## Tech Stack

Vanilla HTML, CSS, and JavaScript, plus basic Python (Flask) to serve the site.
SQLite stores the plant data. No frameworks or libraries.
