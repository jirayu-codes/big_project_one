# PlantPal — Roadmap

## Current State

Nothing is built yet. We only have the project idea in `design.md` and this
constitution.

## Next Steps

Start with the walking skeleton — the thinnest working version:

1. Add a plant (its name and how often it needs water).
2. See the plant listed on the page.
3. See when that plant is next due to be watered.

## After That

Grow features on top of the working skeleton, in this order:

1. Track other care types (fertilize, repot) with their own schedules.
2. Mark a plant as "watered today" so its due date updates.
3. Show a "due soon" or "overdue" list on the main page.

## Long-Term Vision

A polished, single-user tool that you actually use every day to keep your
plants healthy.
